◇◇카드 정산 시스템 고도화

본 사업은 카드 매출 정산 배치의 처리 시간을 줄이고 정산 오류를 줄이는 것을 목표로 한다. 수행 인력은 다음을 갖추어야 한다. 첫째, Spring Batch 기반 대용량 배치 처리 경험이 5년 이상인 개발자 2명. 둘째, 정산 배치에서 사용하는 Oracle 프로시저를 분석하고 튜닝할 수 있는 DB 전문가 1명(PL/SQL 경력 7년 이상). 셋째, 카드 승인·매입·정산 업무를 3년 이상 수행해 본 업무 분석가 1명. 또한 배치 수행 시간을 기존 대비 30% 이상 줄이기 위해 SQL 튜닝을 수행하여야 한다. 개발 환경은 발주처가 제공하는 Git 저장소와 Jenkins를 사용한다.
