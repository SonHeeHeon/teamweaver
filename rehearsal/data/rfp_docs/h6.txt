제안요청서
◎◎보험 상담 지원 AI 에이전트 구축

1. 현황: 현재 고객센터 챗봇은 규칙 기반 시나리오로 운영 중이며, 이번 사업 이후에도 단순 문의용으로 유지한다. 상담 이력은 Elasticsearch에 쌓이고 있어 검색 원천으로 그대로 쓴다.
2. 목표: 약관·상담 매뉴얼을 근거로 답변 초안을 만드는 상담 지원 AI 에이전트를 구축한다.
3. 요구 사항
 - 약관 문서 검색 증강 생성(RAG) 구조와 벡터 데이터베이스 구축
 - 답변 근거 인용과 할루시네이션 점검 체계(LLM 응용)
 - 개인정보 비식별화 처리(개인정보보호법 준수)
 - 모델 배포·모니터링 체계(MLOps)
4. 인력 요건: LLM 응용 개발 경력 2년 이상 2명, Python 5년 이상 2명, 보험 업무 이해 1명(3년 이상).
5. 우대: LangChain 또는 LangGraph 기반 에이전트 개발 경험, PyTorch 기반 모델 미세 조정 경험.
