과업지시서
□□은행 차세대 정보계 데이터 플랫폼 구축

1. 목적
정보계 데이터를 통합 적재하고 분석 리포트를 일원화한다.

2. 현행 환경
- 계정계는 메인프레임에서 COBOL로 운영 중이며 본 사업 범위가 아니다.
- 대외계 연계는 현재 IBM MQ로 처리하고 있으며, 본 사업은 대외계에서 받은 파일만 적재한다.

3. 과업 범위
- 정보계 데이터 웨어하우스(DW) 재구축
- 일 배치 적재 파이프라인(ETL) 구축 및 Airflow 기반 스케줄링
- 경영 리포트의 Tableau 대시보드 전환

4. 투입 인력 기준
| 역할 | 필요 기술 | 최소 경력 | 인원 |
| 데이터 아키텍트 | 데이터 모델링 | 7년 | 1 |
| 적재 개발 | ETL | 5년 | 2 |
| 적재 개발 | Airflow | 2년 | 1 |
| 리포트 개발 | Tableau | 3년 | 1 |
| 업무 분석 | 은행 업무 | 5년 | 1 |

5. 우대 사항
- Kafka 기반 실시간 적재 구축 경험자 우대
- Spark 대용량 처리 튜닝 경험 보유 시 가점
