제안요청서
◆◆청 통계 분석 시스템 기능 개선 사업

Ⅰ. 사업 개요
1. 사업명: ◆◆청 통계 분석 시스템 기능 개선
2. 사업 기간: 착수일로부터 8개월
3. 추진 배경: 통계 이용자가 늘어 조회 응답이 느려지고, 담당자가 수작업으로 만드는 보고서가 많다.

Ⅱ. 현황
1. 현행 시스템 구성
 - 운영 서버: Unix(AIX) 4대, Linux 6대
 - DBMS: Oracle Database 19c, Tibero 6(보조)
 - WAS: JEUS 8, WebtoB 5
 - 통계 엔진: SAS(본 사업에서 변경 없음)
 - 보고서 도구: 상용 리포팅 솔루션(내부)
2. 연계 현황: 국가통계포털과 Open API로 연계하며, 연계 규격은 변경하지 않는다.

Ⅲ. 사업 내용
1. 조회 성능 개선: 대용량 통계 조회 SQL을 분석·튜닝하고 집계 테이블을 재설계한다.
2. 보고서 자동화: 담당자가 수작업으로 만들던 정기 보고서를 Python 배치로 자동 생성한다.
3. 시각화 화면: 통계 대시보드를 웹 화면으로 신규 구축한다(차트 라이브러리는 수행사 제안).

Ⅳ. 일반 요구사항
1. 웹 접근성·웹 표준을 준수한다.
2. 개인정보보호법 및 기관 보안 지침을 준수하며, 소스코드는 보안 약점 진단 도구로 점검한다.
3. 산출물은 기관 표준 방법론에 따른다.

Ⅴ. 투입 인력
1. 사업관리자: 공공 정보화 사업관리 경력 10년 이상 1명
2. DB 튜닝 전문가: SQL 튜닝 경력 7년 이상 1명(Oracle 환경)
3. 개발자: Python 개발 경력 3년 이상 2명, 웹 화면 개발 경력 3년 이상 1명
4. 품질: 테스트·품질 관리 인력 1명(비상주 가능)
