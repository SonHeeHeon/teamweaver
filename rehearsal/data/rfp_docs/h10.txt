제안요청서
◐◐물류 배송 관제 시스템 구축

1. 추진 배경
배송 차량 위치와 배송 상태를 실시간으로 보는 관제 화면이 없어, 지점마다 전화로 상황을 확인하고 있다.

2. 기존 시스템 구성(참고)
| 구분 | 제품 |
| 주문 시스템 | SAP ERP |
| 창고 관리 | 자체 개발(Java, MySQL) |
| 메시지 | RabbitMQ |
| 인프라 | AWS |
기존 시스템은 본 사업에서 수정하지 않으며, 주문·창고 데이터는 발주처가 제공하는 API로만 받는다.

3. 구축 범위
- 차량 단말 위치 수집 서버(Kafka 수집, Spring Boot)
- 실시간 관제 화면(React, 지도 표시)
- 배송 이력 조회와 지점별 통계
- AWS 위 컨테이너(Amazon EKS) 배포, CI/CD 파이프라인 구성

4. 수행 인력 요건
본 사업 수행 인력은 물류 업무 이해를 갖춘 PM 1명(경력 8년 이상), Spring Boot·Kafka 기반 실시간 수집 개발 경력 4년 이상 2명, React 화면 개발 경력 3년 이상 1명, Amazon EKS 운영 경험 2년 이상 1명으로 구성한다. 지도 API 연동 경험자는 우대한다.
