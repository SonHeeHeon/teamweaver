제안요청서
○○시 통합 민원 포털 재구축 사업

1. 사업 개요
본 사업은 ○○시 통합 민원 포털을 재구축하여 시민 편의를 높이는 것을 목적으로 한다. 사업 기간은 계약일로부터 10개월이며, 사업 예산은 12억 원(부가세 포함)이다.

2. 현황
현행 민원 포털은 2014년에 구축되어 오라클 11g 데이터베이스와 웹로직(WebLogic) 미들웨어 위에서 운영 중이다. 행정정보 공동이용 시스템과 연계되어 있으며, 연계 방식은 이번 사업에서 변경하지 않는다.

3. 과업 내용
가. 응용 시스템은 전자정부 표준프레임워크 4.x를 적용하여 재개발한다.
나. 데이터베이스는 PostgreSQL로 전환하고, 기존 데이터 전체를 새 데이터베이스로 옮긴다.
다. 사용자 화면은 웹 표준을 준수하여 Vue로 구현한다.
라. 개발 산출물은 행정안전부 시큐어 코딩 가이드를 준수하여야 하며, 소스코드 보안 약점 진단 결과를 제출한다.

4. 투입 인력 요건
수행사는 Java 기반 전자정부 표준프레임워크 개발 경력 5년 이상인 인력 2명 이상을 투입하여야 한다. 데이터를 옮기는 인력은 데이터 이행 경력 3년 이상 1명을 두며, PostgreSQL 운영 경험을 갖추어야 한다. 공공 분야 정보화 사업 수행 경험이 있는 사업관리자(PM)를 지정한다.
