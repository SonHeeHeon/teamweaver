TeamWeaver 실제 데이터 스키마 입력 양식

기술 이력 시스템과 피어 리뷰가 실제로 어떤 항목을 어떤 형태로 갖고 있는지 알려 주시는 양식입니다. 채운 결과(JSON)는 Claude와 Codex가 함께 읽고 입력 기능·가상 데이터·실험을 실제 형태에 맞춥니다.

입력 전 주의
· 실명, 사번, 고객사명, 실제 동료의 리뷰 원문은 넣지 마세요. 예시값은 가리거나 비슷한 가짜 값으로 바꿔 주세요.
· 항목 정의·선택지 목록도 사내 공유 기준상 외부 AI에 제공해도 되는지 먼저 확인해 주세요.
· 모르는 칸은 비워 두거나 "모름"이라고 적으면 됩니다. 숫자는 대략적인 감으로 충분합니다.
· 작성 중인 값은 이 브라우저에 자동 저장됩니다. 다 쓰면 아래 "JSON 저장"을 눌러 teamweaver/private/schema-intake.json으로 두세요(Git에 올라가지 않는 폴더).
