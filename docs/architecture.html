TeamWeaver — 인력 배치 최적화 한 장 구조

실제 시스템 CSV 형식 → 엄격 검증 → 점수 → 수학 최적화 → 독립 검증 → 대안·시뮬레이션 → 근거 대조 AI 설명 → 화면·PDF. 데이터는 모두 가상, 사업 효과는 미검증(NOT_CALIBRATED).

입력과 점수

1CSV 묶음

  • 사람·기술 경력·사업·요건·가용률·과거 이력·동료 평가·현재 배치
  • 업로드 또는 시연 묶음(연초 계획 / 운영 중)
core/ingest · api/demo_presets

2엄격 검증

  • 오류는 파일·줄·칸까지, 통과 전엔 전환 안 함
  • 경력 개월 → 숙련 레벨, 최근 10년만 읽기
core/ingest/loader · convert

3관계 그래프

  • 누가 누구와 언제 몇 달 일했나
  • "익숙한 쌍" = 최근 36개월 중 12개월 이상
core/graph/memory_graph

4점수

  • S 기술 적합: 요구 대비 레벨
  • C 협업: 0.4·함께한 개월(12개월 포화) + 0.6·동료 평가(LLM 글 판정)
core/scoring/engine
계산

5수학 최적화(MILP, HiGHS)

최대화 Σ S·투입률 + λ·Σ C(상위 200쌍) − μ·익숙한 쌍 − 100·빈자리
  • 제약: 월 예산 · 월별 가용률 · 등급 정원 · 동시 사업 ≤3 · 최소 투입률
  • 시드 4개 동시 탐색, 증명 상한 기록 · 대안 B~D는 구성이 다르고 품질 ≥ A의 95%
core/optimize/milp · highs_portfolio · alternatives

6독립 검증

  • 솔버 답을 원자료로 다시 검사: 정수성·범위·제약·목적값
  • 통과한 해만 화면에
core/optimize/validation

7평가기

  • 어떤 배치든 같은 목적·제약으로 다시 채점
  • 교체·보강·미리 계산 확인에 공통 사용
core/evaluate/plan_eval

8교체 검토

  • 한 사람 교체 → 점수 변화(참고값)·위반 경고
  • 적용·되돌리기·이력
api/routes/whatif · plans

9운영 중 편성

  • 기존 배치는 고정, 최대 K명만 이동
  • K=0~3 개선량(최적 증명, 갭 0)
core/optimize/incremental · core/evaluate/operating

10사업 보강

  • 후보 순위(근사로 거른 뒤 정확 채점)

core/evaluate/staffing_sim
