THREE PHASES

모델 검증, 기술 비교, 개선을 분리합니다

Phase 0 · 기본 모델 검증

작은 문제의 정답 대조, 행동 규칙, 목적함수 항의 규모, pair 절삭 손실을 먼저 검증합니다.

Phase 1 · 솔버 비교

검증된 동일 모델로 CBC·HiGHS·SCIP의 순수한 성능 차이를 측정합니다.

Phase 2 · 모델 개선

우승 솔버에서 warm start, pair 절삭, 분해와 CP-SAT 별도 모델을 평가합니다.

PHASE 0

기본 모델 자체를 먼저 시험합니다

작은 문제의 정답

직접 열거 가능한 규모에서 독립 계산한 최적해와 solver 결과가 같은지 확인합니다.

행동 불변식

사람 순서를 바꿔도 점수가 같고, 예산·가용률을 줄였을 때 가능한 해가 모순되게 좋아지지 않아야 합니다.

점수 항 크기

스킬·시너지·과숙련·미충원 항의 기여도를 규모별로 재서 한 항이 사람 수 때문에 압도하는지 확인합니다.

근사 손실

전체 pair와 1,000·5,000 pair 절삭 결과를 작은 규모에서 비교해 속도를 위해 잃은 품질을 수치화합니다.

TRUST BOUNDARY

지금 믿을 수 있는 것과 없는 것

판단현재 가능 여부근거
수식·코드가 같은 문제를 푸는가검증 가능작은 정답 문제, 독립 목적값·제약 검산
합성 300명 문제에서 어느 솔버가 빠른가잠정 검증 가능동일 모델·환경·입력의 반복 실험
실제 데이터에서도 같은 순위인가아직 불가실제 희소도·수요 압박·리뷰 구조가 없음
추천 팀이 실제 프로젝트 성과를 높이는가현재 불가과거 배치와 성과 결과 데이터가 전혀 없음
λ·μ·미충원 벌점이 현실에 맞는가현재 불가기본값은 설계 가정이며 실성과로 학습·검증되지 않음

합성 성과를 현재 수식으로 만든 뒤 같은 수식의 정확성을 검증하면 순환 논증이 됩니다. 합성 성과는 파이프라인 테스트에는 쓸 수 있지만 사업 효과의 증거로 사용하지 않습니다.

REAL-DATA GATE

24시간 최종 판정 전에 필요한 최소 실데이터

인력 스냅샷

익명 ID, 등급·단가, 기술·숙련도·근거일, 월별 가용률이 필요합니다.

프로젝트 요구

기간, 역할·등급 정원, 필수 기술·수준, 월 예산이 필요합니다.

과거 배치

프로젝트·인력·역할·기간·투입률과 실제 변경 이력이 필요합니다.

독립 성과

일정·예산 편차, 결함·재작업, 고객 평가, 수익성처럼 배치 점수에서 만들지 않은 결과가 필요합니다.

성과 원자료를 당장 받을 수 없어도, 익명화한 분포 요약만 있으면 solver 성능 실험의 시나리오를 현실에 가깝게 조정할 수 있습니다.

SCENARIOS

한 종류의 합성 데이터에 맞추지 않습니다

기본형

현재 생성기 그대로. 최대 수요/가용량 비율이 0.85 이하인 기존 PoC 분포입니다.

가용량 압박형

월별 수요/가용량을 0.95~1.05로 올려 미충원과 탐색 난도를 드러냅니다.

예산 압박형

프로젝트별 예산/명목 인건비 중앙값을 0.80~0.90으로 맞춰 예산 제약을 강하게 만듭니다.

시너지 밀집형

평균 협업 차수를 10~12로 높여 시너지·과숙련 보조변수가 많은 경우를 시험합니다.

시나리오는 solver 결과를 보고 조정하지 않습니다. 입력 통계가 목표 구간에 드는지만 사전 검사하고, 실패하면 해당 데이터셋을 명시적으로 무효 처리합니다.

statusoptimal · feasible_limit · no_incumbent · infeasible · errorPuLP의 단순 상태값 대신 솔버 고유 상태와 incumbent 존재를 함께 확인

FAILURE CONTAINMENT

한 솔버가 죽어도 실험 전체는 계속됩니다

실행별 자식 프로세스

Python 오류, native solver crash, 메모리 급증을 한 셀 안에 가둡니다. 부모 러너는 다음 셀을 계속 실행합니다.

240초 전체 마감

모델 생성 뒤 남은 시간만 솔버에 줍니다. 전체가 240초를 넘으면 서비스 기준 실패입니다.

12GB 보호선

프로세스 트리 RSS가 12GB를 넘으면 종료하고 memory_limit으로 기록해 OS와 러너가 살아남게 합니다.

원시 로그 보존

성공·실패 모두 stdout, stderr, solver 로그, 예외 종류를 남깁니다. 비밀값과 환경변수 값은 저장하지 않습니다.
