  4. C6 입력: 필수 기술, 미기재 등급 인원, 최소 투입률 같은 배치 규칙을 사용자 컬럼·정책 설명에서 확정합니다. 두 수학 모델과 Claude 평가기를 함께 동기화하고 Phase 0를 다시 돌립니다.
  5. 규모·솔버 확정: 위 규칙이 확정되면 새 동결 입력에서 300/60 등 큰 규모를 다시 비교합니다. 상용 솔버 1개는 라이선스 확보 후 동일 조건으로만 비교합니다.
  6. 제품·보존: Claude 영역의 CSV 계약·PDF 보안·리뷰 근거·MemoryGraph 보완과, 사용자 지정 보관 위치를 쓰는 C4 원자료 보존을 이어갑니다.

실제 사람의 민감한 이력이나 프로젝트 성과를 요구하지 않습니다. 공유 가능한 컬럼 이름·형식·의미·선택지·분포 설명으로 합성 데이터를 만듭니다. 현실 성과 연결 자료가 없으면 사업 효과는 계속 검증되지 않은 상태로 남겨야 합니다.

10. 설계에서 조정한 작은 결정

체크포인트마다 별도 최고 역량 리뷰를 유지했고, 진단과 비활성 보정은 같은 G1 커밋에 묶었습니다. 기존 표시 형식을 재사용하는 내부 helper를 추가했습니다. 모순된 상한을 버리지 않고 BOUND_INVALID로 남겼습니다. C0의 작은 잔차 거절 전용 테스트는 원본 실패 보존·최종 엄격 통과를 검증하는 테스트로 바꿨지만 기존 6개 회귀 테스트는 그대로입니다.

Phase 0 스크립트는 --help를 지원하지 않아 확인 명령이 한 번 더 실행됐습니다. 원래 추적 파일을 바이트 단위로 복원하고 최종 증거는 새 경로에 따로 저장했습니다. 개발 로그에는 이 일도 기록했습니다. 최종 독립 리뷰 판정과 더 자세한 근거는 docs/superpowers/reviews/2026-10-05-c1-final-review.md에 남깁니다.
